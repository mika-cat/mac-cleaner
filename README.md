# Mac 清洁大师 (Mac Cleaner Master)

> 极致极简，释放极致空间。专为 AI Agent 打造的 macOS 深度清理技能。

## 简介
macOS 的“系统数据”常常莫名其妙地占据大量空间，而传统的清理软件往往无法触及开发者工具和隐藏缓存的深水区。

本 Skill 赋予你的 AI Agent 深度扫描和安全清理的能力。通过精准锁定 `~/.cache`、`~/.npm`、`~/.ollama` 等隐藏的“空间杀手”（实测中可轻松释放 15GB+ 的空间），配合突破系统权限的引导清理流程，它能为你找回丢失的硬盘空间。

## 特性 (Features)
- 👁️ **深度隐形扫描**：直击普通清理工具看不见的开发者隐藏缓存。
- 🛡️ **安全至上**：严格的执行准则，清理前必经用户授权，绝不误删重要配置。
- 🤝 **突破权限封锁**：独创“终端扫描 + 交互式可视化引导”双模式，完美应对 macOS TCC 隐私保护。

## 安装指南 (Installation)

1. 打开终端 (Terminal)。
2. 确保你的全局配置文件目录存在。如果不存在，请运行：
   ```bash
   mkdir -p ~/.gemini/config/skills/
   ```
3. 将包含 `SKILL.md` 的整个 `mac-cleaner` 文件夹，复制或移动到上述目录中：
   ```bash
   # 最终的文件结构应该如下所示：
   # ~/.gemini/config/skills/mac-cleaner/SKILL.md
   ```

## 如何使用 (Usage)

安装完成后，在与你的 AI 助手对话时，直接输入以下指令即可唤醒清洁大师：

- *“调用 mac-cleaner 帮我清理一下电脑空间”*
- *“我的 Mac 存储满了，帮我瘦个身”*
